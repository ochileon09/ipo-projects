# 성별 배정 운영 안내

자동·수동 배정은 같은 학년, 관리자 확인을 마친 같은 성별, 호실 정원, 승인된 분리 조건을 모두 만족해야 합니다. 생활 적합도 점수는 이 필수 조건을 통과한 학생끼리만 비교합니다.

## 처음 적용할 때

1. 관리자 화면의 **학생 성별 확인·관리**에서 학교 명단을 대조하고 확인·저장합니다. 미응답 학생은 명단의 실제 이름도 입력합니다.
2. **명단·건물 설정 → 건물 구조 직접 관리**에서 배정 성별을 정합니다. 건물 전체 전용 또는 ‘하위 구역에서 구분’을 선택한 뒤 층·구역·호실을 지정할 수 있습니다.
3. 학년·성별 수용 현황에서 부족 자리와 대기를 확인합니다. 미설정 호실은 자동 배정에 사용하지 않습니다.

기존 응답과 미응답 학생의 성별은 미확인입니다. 이름·학번으로 추측하거나 임의로 채우지 않습니다. 학생이 설문에서 성별을 선택해도 관리자 확인 전에는 대기합니다. 확인 기록과 다른 성별의 새 응답이 들어오면 재확인이 필요합니다. ‘미확인’ 재제출만으로 기존 공식 확인을 지우지는 않습니다.

## 수동 배치와 최종 확정

- 빈 침대 이동과 자리 교환 모두 도착할 방의 학년·성별·정원·분리 조건을 검사합니다. 교환 상대가 돌아갈 방도 검사합니다.
- 최종 확정은 가상 학생 제거와 활성 대상의 성별 확인을 마친 뒤 가능합니다. 최종 확정 중에는 확인 기록과 구조·분리 조건·수동 배치를 바꾸지 못합니다.
- 새 설문과 일반 생활 답변 변경은 기존 확정 원본을 변경하지 않습니다. 성별 충돌·신원 충돌로 안전성을 확인할 수 없는 자리는 유효 배정 표시에서 제외하고 관리자 재검토를 안내합니다. 확정 원본은 DB에 보존합니다.
- 이전 버전의 성별 검증 없는 확정 배정표도 원본을 보존합니다. 확정 해제 후 학생 확인과 공간 설정을 마쳐 다시 확정합니다.

## 테스트 모드

학년별 가상 남학생·미확인 수를 정하며 나머지는 가상 여학생입니다. 실제 응답이 없는 학번만 생성합니다. 실제 학생의 성별 확인 기록은 변경하지 않고, 미확인 실제 응답을 같은 학번의 가상 학생으로 대체하지 않습니다. 종료 버튼은 가상 학생만 제거합니다.

- 변경 충돌: 설문·확인 명단·구조가 바뀌면 배치 버전을 갱신하여 오래된 수동 배치·확정을 거절
